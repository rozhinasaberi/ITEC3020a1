# ITEC3020a1

A static frontend assignment for ITEC 3020 that presents a themed online sticker and planner shop concept.

## What This Project Is About

This project focuses on frontend layout, styling, and visual presentation. It uses HTML and CSS to build a storefront-style page featuring themed products, images, navigation, and a shopping-inspired layout.

This is a **frontend web design assignment**.

## Features

- static storefront homepage
- themed product images
- navigation and category layout
- custom CSS styling
- course-assignment structure

## Tech Stack

- HTML
- CSS

## Main Files

- `index.html` - main web page
- `styles.css` - site styling

## Open Locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 5500
```
